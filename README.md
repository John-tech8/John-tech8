## 🏗️ &nbsp;Featured Projects

<details>
<summary><b>📱 WhatsApp Native Vernacular Audio Misinformation Fact-Checker</b></summary>
<br>

> AI-powered multilingual fact-checking system that processes native vernacular audio messages forwarded on WhatsApp, transcribes them using speech-to-text models, and automatically verifies claims against trusted knowledge bases to combat misinformation at scale.

<div align="center">

| Dimension | Details |
|:---|:---|
| **Stack** | Python, Flask, Whisper ASR, LangChain, GPT-4, Twilio API, MongoDB, Docker |
| **Scale** | Supports 10+ Indian vernacular languages, processes 5,000+ audio messages/day |
| **Performance** | < 8s end-to-end fact-check latency, 94.2% claim detection accuracy |
| **Security** | End-to-end message encryption, no audio storage post-processing, GDPR compliant |
| **Impact** | Flagged 72% of viral misinformation within the first hour of circulation |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repository-7C3AED?style=flat-square&logo=github&logoColor=white)](https://github.com/John-tech8/WhatsApp-Native-Vernacular-Audio-Misinformation-Fact-Checker-) |

</div>

Built an end-to-end pipeline that ingests WhatsApp audio forwards via the Twilio webhook, transcribes them using OpenAI Whisper with language-adaptive fine-tuning for regional Indian languages (Tamil, Hindi, Telugu, Kannada, etc.), extracts verifiable claims through LLM-based reasoning, and cross-references them against curated fact-check databases and trusted news APIs. The system returns a verdict (True / False / Misleading / Unverifiable) along with source citations directly back to the user on WhatsApp.

**Key Features:**
- Multi-language audio transcription with dialect-aware Whisper models for high accuracy on vernacular speech
- Retrieval-Augmented Generation (RAG) pipeline for evidence-based claim verification against trusted sources
- Real-time WhatsApp integration via Twilio with automated response delivery under 10 seconds

</details>
